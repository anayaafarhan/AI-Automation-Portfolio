# AI-Automation-Portfolio
A collection of AI automation projects (n8n, APIs, chatbots)

## Projects

- [`airbnb-cinematic-video-generator/`](airbnb-cinematic-video-generator/) — One command turns a folder of property photos/videos into a 20–30s vertical (9:16) luxury real-estate reel: quality-based shot selection, an editable storyboard, per-shot "virtual camera" motion (push-in/pull-back/pan/hold) with selective sky-layer parallax, cinematic color grade, restrained crossfades, synthesized/user music, and premium typography. 100% free/local (Python + ffmpeg, no pretrained model weights, no paid APIs) — includes a `--demo` mode for client-ready samples.
